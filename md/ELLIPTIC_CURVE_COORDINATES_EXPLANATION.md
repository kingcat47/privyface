# 타원곡선 좌표 생성 과정 설명

## 타원곡선 좌표란?

타원곡선 좌표는 ZK-SNARK Proof의 핵심 구성 요소입니다. 모든 제약 조건(constraints)이 만족되었음을 증명하는 수학적 좌표입니다.

## 좌표 생성 과정

### 1단계: 제약 조건 생성

```typescript
// face-verification-program.ts

// 제약 조건 1: 얼굴 유사도 검증
isSimilar.assertTrue("얼굴 유사도가 임계값을 초과했습니다");
// → 제약 조건: 유클리드 거리 <= 임계값

// 제약 조건 2: 머클 트리 루트 계산 (검증은 서버에서)
const computedRoot = merklePath.computeRoot(leaf);
// → 제약 조건: 머클 경로 계산
```

### 2단계: 다항식 변환

모든 제약 조건이 다항식(polynomial)으로 변환됩니다:

```
제약 조건 1: distance <= threshold
    ↓
다항식 1: f₁(x) = distance - threshold <= 0

제약 조건 2: computedRoot = hash(hash(...))
    ↓
다항식 2: f₂(x) = computedRoot - hash(...) = 0
```

### 3단계: 타원곡선 변환

다항식이 타원곡선 위의 점들로 변환됩니다:

```
다항식들
    ↓
타원곡선 위의 점들
    ↓
pi_a, pi_b, pi_c (좌표)
```

### 4단계: Proof 생성

타원곡선 점들의 조합이 Proof가 됩니다:

- **pi_a**: G₁ 그룹의 점 (첫 번째 증명 조각)
  - 좌표: [x, y, z] (3개)
- **pi_b**: G₂ 그룹의 점 (두 번째 증명 조각)
  - 좌표: [[x₁, y₁], [x₂, y₂], [x₃, y₃]] (2x2 배열)
- **pi_c**: G₁ 그룹의 점 (세 번째 증명 조각)
  - 좌표: [x, y, z] (3개)

## 핵심 개념

### 왜 타원곡선을 사용하나요?

1. **암호학적 안전성**: 타원곡선 암호학은 매우 안전합니다
2. **간결성**: 복잡한 계산을 작은 좌표로 표현할 수 있습니다
3. **검증 가능성**: 서버는 좌표만으로 모든 조건이 만족되었음을 확인할 수 있습니다

### 좌표의 의미

- **pi_a, pi_b, pi_c**: 각각 다른 타원곡선 그룹(G₁, G₂)의 점입니다
- **좌표 값**: 매우 큰 정수 (256비트 이상)
- **조합**: 이 세 점의 조합이 "모든 조건이 만족되었다"는 증명입니다

### 검증 과정

서버는 이 좌표들을 사용하여:
1. 타원곡선 위의 점들이 유효한지 확인
2. 모든 제약 조건이 만족되었는지 확인
3. Public Input과 일치하는지 확인

## 정리

- 타원곡선 좌표는 **모든 제약 조건이 만족되었다는 증명**입니다
- 좌표 생성은 **자동으로** 수행됩니다 (o1js 내부)
- 좌표는 **매우 큰 정수**로 표현됩니다
- 서버는 이 좌표만으로 **모든 검증**을 수행할 수 있습니다
